# Destí

Planeje viagens sem planilha: roteiro dia a dia, viagens por vários países, orçamento, divisão de gastos e reservas num só lugar.

- **Site:** https://nathansussaio.github.io/Dest-/ (depois: https://destiapp.com.br)
- **Código do app** (iPhone, Android e web, em Expo + React Native): pasta [`app/`](app/). Instruções em [`app/LEIA-ME.md`](app/LEIA-ME.md).
- **Como o site é publicado:** a cada mudança em `app/`, o GitHub gera o site oficial (`expo export`) e publica nesta mesma pasta. Veja `.github/workflows/site.yml`.
